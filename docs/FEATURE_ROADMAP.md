# minstock 기능 로드맵

이 문서는 조회 전용 기능의 구현 순서와 완료 기준을 관리합니다. 기능마다 별도 브랜치에서
개발하고 테스트한 뒤 `main`에 병합합니다. 주문·자동매매 기능은 이 로드맵에 포함하지 않습니다.

## 8. 종목별 뉴스·공시

- 종목 상세 `Tab`으로 차트/뉴스·공시 전환, 목록 이동과 `Enter`/`o` 원문 열기.
- NAVER API HUB 종목명 뉴스 검색, DART 종목코드→회사 고유번호 매핑과 최근 90일 공시.
- 신규 신청 중단된 NAVER 개발자센터 대신 API HUB 주소·인증 헤더 사용, 옛 기본 설정 주소 자동 전환.
- Alpha Vantage 배당 키를 재사용해 티커별 미국 뉴스와 관련도 조회.
- 제목·출처·시각·원문 메타데이터만 저장하고 중복·HTML·터미널 제어문자 제거.
- 공급자별 30분 캐시, 조회 실패 시 캐시 유지와 재시도 대기, 호출 한도 보호.
- API 키 미설정·실패·정상 빈 결과 구분, 종목 전환 후 오래된 응답 무시.
- 공급자 응답 계약, 캐시 복원·부분 실패·동시 호출·응답 순서·화면 크기 테스트 통과.
- 2026-10-05 AAPL 실제 뉴스 48건 조회 성공. NAVER·DART 키 미등록으로 국내 실서버 확인은 남아 있다.

## 7. 시장 급등 스캐너

- 키움 `ka10027`, `ka10023`, `ka10032` 순위를 최대 3페이지씩 수집하고 중복을 제거한다.
- KRX 정규장 기준으로 기본 최대 20종목을 최신 시세와 1분봉으로 분석한다.
- 5분 등락률과 최근 완료 5분 / 직전 5분 거래량 배수를 실제 분봉에서 계산한다.
- 거래대금 백만원 → 원화 변환, 체결강도 미제공 표시, 데이터 부족 종목 제외를 적용한다.
- 급등 화면에서 계좌 폴링과 별도로 60초 간격 조회하며 마지막 정상 결과를 SQLite에 저장한다.
- 조회 실패와 캐시, 부분 순위 실패, 제한된 분석 범위, 정상 빈 결과를 구분한다.
- 설정에서 전체/KOSPI/KOSDAQ, ETF·ETN 제외, 후보 수와 정량 조건을 조절한다.
- 실계좌 장중 스모크 테스트는 사용자 키움 계좌로 별도 확인한다. 미국·NXT는 후속 범위다.

2026-10-05 장외 실서버 검증:

- 기존 OS 키체인 자격증명으로 실서버 인증 성공.
- 세 종류의 시장 순위 API 오류 없이 1,082개 중복 제거 후보 수집.
- 현재가·고점·1분봉 실제 응답 확인. 이전 거래일 분봉은 현재 급등 판단에서 제외.
- 거래대금 순위 밖 후보의 거래대금 누락을 발견해 `ka10003` 종목별 체결정보로 보강.
- 원화 누적거래대금과 체결강도 실제 응답 확인 및 독립 캐시 갱신 제한 검증.
- 재실행 가능한 opt-in `TestScannerLiveSmoke` 추가. 실시간 5분 계산은 장중 검증이 남아 있다.

## 3. 데이터 출처와 갱신 상태

- 통합 자산 금액에 `실시간`, `일부 캐시`, `캐시` 상태를 표시한다.
- 증권사별 자산 행에 각 증권사의 데이터 상태와 기준 시각을 표시한다.
- USD/KRW에는 환율을 제공한 증권사와 환율 상태를 표시한다.
- 한 증권사의 캐시 데이터가 다른 증권사의 실시간 상태를 덮어쓰지 않게 한다.
- 캐시 복원 또는 일시적인 API 실패 시 실시간으로 오인하지 않게 한다.

완료 내용:

- 통합 자산 금액에 실시간·혼합·캐시 상태를 표시한다.
- 넓은 화면에서는 증권사별 기준 시각까지 표시하고 80열에서는 상태를 축약한다.
- USD/KRW 옆에 `NH·실시간`, `키움·캐시`와 같은 출처를 표시한다.
- NH의 5초 공유 캐시와 장애 시 마지막 정상 잔고 폴백을 캐시로 구분한다.

## 4. 배당 현황과 예상 배당금

- 구현 전에 미국 주식·ETF 배당 데이터의 라이선스, 갱신 주기, API 안정성을 검토한다.
- 종목별 최근 배당과 지급 주기에서 연간 예상 배당금을 계산한다.
- 월별 지급 예정액, 세전·세후 예상액, 증권사별 환율 기반 원화 환산액을 표시한다.
- 추정치와 확정 지급액을 명확히 구분한다.

완료 내용:

- Alpha Vantage `DIVIDENDS`를 데이터 소스로 선택하고 OS 키링에 API 키를 저장한다.
- 무료 사용량을 고려해 종목별 응답과 무배당 응답을 24시간 SQLite 캐시한다.
- 최근 12개월 배당으로 연간 세전 예상액을 계산하고 미국 원천징수 15% 기준 세후액을
  함께 표시한다.
- 같은 종목을 여러 증권사에 보유해도 수량을 합산하되 원화 환산은 각 증권사의 환율을
  독립적으로 적용한다.
- 이미 선언된 미래 배당일을 우선하고, 나머지는 최근 지급 이력 기반 예상 월로 표시한다.

## 5. 목표 비중과 리밸런싱 조회

- 사용자가 종목 및 현금의 목표 비중을 로컬에 저장할 수 있게 한다.
- 목표 비중, 현재 비중, 편차와 종목·시장·통화 집중도를 표시한다.
- 매수·매도 수량을 지시하지 않고 분석 정보만 제공한다.

완료 내용:

- `8 비중` 화면에서 통합/NH/키움 범위를 `Tab`으로 전환한다.
- 현재 보유종목과 현금을 자동 구성하고 `Enter`/`e`로 목표 비중을 편집하며 `a`로
  미보유 종목을 검색해 추가한다.
- `r`로 현재 비중을 복사하며 합계가 100%일 때만 `s`로 저장한다.
- 편차 ±2% 이내는 적정, +2% 초과는 초과, +5% 초과는 집중, -2% 미만은 부족으로 표시한다.
- 주문이나 매수·매도 수량 제안에는 연결하지 않는다.

## 6. 가격·수익률 알림

- 목표가 도달, 일간 변동률, 보유 손실률, 자산 비중, API 연결 실패 조건을 지원한다.
- 1차 구현은 로컬 TUI 알림 이력과 확인 상태를 제공한다.
- macOS 알림은 TUI 동작과 규칙 저장이 안정화된 뒤 별도 기능으로 확장한다.

완료 내용:

- `9 알림` 화면에서 `Tab`으로 알림 이력과 목표가 규칙을 전환한다.
- `a`에서 `티커 목표가`를 입력해 현재가 기준 이상/이하 도달 규칙을 SQLite에 저장한다.
- 일간 변동률 ±5%, 보유 손실률 -10%, 단일 종목 비중 30%, 연결 실패 3회 연속을 기본
  조건으로 평가한다.
- 같은 조건은 하루 한 번만 기록하며 `x` 또는 `X`로 선택·전체 확인 상태를 저장한다.
- 주문이나 OS 알림은 실행하지 않고 로컬 조회 이력으로 제한한다.
