# minstock 기능 로드맵

이 문서는 조회 전용 기능의 구현 순서와 완료 기준을 관리합니다. 기능마다 별도 브랜치에서
개발하고 테스트한 뒤 `main`에 병합합니다. 주문·자동매매 기능은 이 로드맵에 포함하지 않습니다.

## 진행 현황

| 순서 | 기능 | 상태 | 브랜치 | 완료 기준 |
|---:|---|---|---|---|
| 1 | 포트폴리오 성과 기록 | 완료 | `feature_portfolio_snapshots`, `feature_portfolio_performance`, `feature_performance_line_chart` | 일별 스냅샷과 일·주·월·연 성과 표/선 그래프 |
| 2 | 증권사별 자산 현황 | 완료 | `feature_broker_asset_breakdown` | 증권사별 총자산·손익·수익률·미국자산·환율·비중 |
| 3 | 데이터 출처와 갱신 상태 | 완료 | `feature_data_provenance_status` | 금액의 실시간/캐시 상태와 환율 제공 증권사 표시 |
| 4 | 배당 현황과 예상 배당금 | 예정 | - | 최근 배당, 연간 예상액, 월별 캘린더, 세전·세후·원화 환산 |
| 5 | 목표 비중과 리밸런싱 조회 | 예정 | - | 목표/현재/편차와 집중도 표시, 주문·매매 지시 없음 |
| 6 | 가격·수익률 알림 | 예정 | - | 목표가·변동률·손실률·비중·연결 실패의 TUI 알림 이력 |

## 3. 데이터 출처와 갱신 상태

- 통합 자산 금액에 `실시간`, `일부 캐시`, `캐시` 상태를 표시한다.
- 증권사별 자산 행에 각 증권사의 데이터 상태와 기준 시각을 표시한다.
- USD/KRW에는 환율을 제공한 증권사와 환율 상태를 표시한다.
- 한 증권사의 캐시 데이터가 다른 증권사의 실시간 상태를 덮어쓰지 않게 한다.
- 캐시 복원 또는 일시적인 API 실패 시 실시간으로 오인하지 않게 한다.

완료 내용:

- 통합 자산 금액에 실시간·혼합·캐시 상태를 표시한다.
- 넓은 화면에서는 증권사별 기준 시각까지 표시하고 80열에서는 상태를 축약한다.
- USD/KRW 옆에 `NH·실시간`, `키움·캐시`와 같은 출처를 표시한다.
- NH의 5초 공유 캐시와 장애 시 마지막 정상 잔고 폴백을 캐시로 구분한다.

## 4. 배당 현황과 예상 배당금

- 구현 전에 미국 주식·ETF 배당 데이터의 라이선스, 갱신 주기, API 안정성을 검토한다.
- 종목별 최근 배당과 지급 주기에서 연간 예상 배당금을 계산한다.
- 월별 지급 예정액, 세전·세후 예상액, 증권사별 환율 기반 원화 환산액을 표시한다.
- 추정치와 확정 지급액을 명확히 구분한다.

## 5. 목표 비중과 리밸런싱 조회

- 사용자가 종목 및 현금의 목표 비중을 로컬에 저장할 수 있게 한다.
- 목표 비중, 현재 비중, 편차와 종목·시장·통화 집중도를 표시한다.
- 매수·매도 수량을 지시하지 않고 분석 정보만 제공한다.

## 6. 가격·수익률 알림

- 목표가 도달, 일간 변동률, 보유 손실률, 자산 비중, API 연결 실패 조건을 지원한다.
- 1차 구현은 로컬 TUI 알림 이력과 확인 상태를 제공한다.
- macOS 알림은 TUI 동작과 규칙 저장이 안정화된 뒤 별도 기능으로 확장한다.
